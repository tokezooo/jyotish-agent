# Timing

Use timing techniques as windows and themes, not guaranteed event dates.

- Vimshottari describes an active symbolic period; it does not guarantee an event.
- Transits are anchored to the calculation's explicit reference date.
- State the date or window used when it affects the answer.
- For approximate birth time, disclose material house or divisional-chart sensitivity.
- For unknown birth time, request a bounded range before making strong house-sensitive
  or varga-sensitive conclusions.
- A follow-up about a narrower window is normally a stateless recalculation, not a new
  ResearchRun.

Avoid false precision. Prefer “this window is more supportive/challenging for…” over
“this will happen on…”.
