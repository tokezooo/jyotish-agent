# Calculation scope and timing

Choose the smallest useful scope for a focused natal question:

- D1 for natal foundation and relevant houses/lords.
- D9 only when strength or maturation materially affects the question.
- D10 for profession, role expression, and career detail.
- `shadbala` when comparative planetary strength matters.
- `transits` for a stated reference date or bounded near-term window.
- `ashtakavarga` only when the question needs transit support by sign.
- `varshaphal` only for an explicitly annual question.

Do not request unsupported modules or broad yoga scans. Ascendant, houses,
planets, panchanga, and Vimshottari are chart facts, not calculation module
names; omit optional modules when those facts are sufficient.

Use timing as symbolic windows and themes, not guarantees. State the reference
date or window used. For approximate birth time, disclose material house or
divisional sensitivity. For an unknown birth time, request the bounded range
required by the advertised tool before making a house-sensitive or
varga-sensitive statement.
