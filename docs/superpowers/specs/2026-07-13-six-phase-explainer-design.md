# Интерактивное объяснение шести фаз Jyotish Research Agent

## Цель

Создать автономную HTML-страницу, которая за 5–8 минут объясняет Владу, как проект превратился из вычислительного ассистента в воспроизводимый исследовательский инструмент. Страница не обучает внутренним API и структуре базы данных; она показывает, что происходит с вопросом пользователя, зачем нужен каждый этап и какой результат появляется на выходе.

## Формат

Основная метафора — «путешествие вопроса через небесную лабораторию». Один пример карьерного вопроса проходит через шесть последовательных фаз. Пользователь может запустить автоматическое прохождение, двигаться вперёд и назад вручную или выбрать фазу на орбитальной карте.

## Содержание

### Вступление

- Короткое сравнение: раньше система рассчитывала и объясняла; теперь создаёт проверяемое исследование.
- Формула результата: вопрос → план → факты и источники → утверждения → проверенный memo → повторное воспроизведение.
- Главная кнопка: «Запустить путешествие вопроса».

### Шесть фаз

1. **Исследование получает память.** Создаётся отдельный защищённый ResearchRun, который не зависит от истории чата.
2. **Порядок становится обязательным.** Система проверяет безопасность вопроса, рассчитывает факты и не позволяет перепрыгнуть этапы.
3. **Ответ становится проверяемым.** Выводы связываются с фактами и источниками; финальный текст появляется только после проверки.
4. **Вопрос получает план и библиотеку.** Система определяет поддерживаемый сценарий, выбирает нужные методы и использует только одобренные фрагменты источников.
5. **Неопределённость становится видимой.** Часовой пояс и неточное время рождения проверяются; нестабильные выводы получают ограничения. Готовый результат можно воспроизвести без нового обращения к модели.
6. **Система проходит стресс-тест.** Проверяются сбои, повторы, повреждённые данные, приватность и вредоносные инструкции. Результат сопровождается честным списком незакрытых внешних проверок.

Для каждой фазы показываются три коротких блока: «Что происходит», «Зачем это нужно», «Что получает Влад».

## Живой результат

Справа находится одна карточка исследования, которая меняется вместе с фазой:

- исходный вопрос;
- созданный run;
- выбранный план;
- вычисленные факты;
- одобренные источники;
- связанные claims;
- готовый memo и совпавший replay hash.

Карточка не имитирует настоящий расчёт и не показывает вымышленные астрологические значения. Она демонстрирует структуру и уровень доверия к результату.

## Визуальный язык

- Направление: «небесная лаборатория», не эзотерический лендинг и не технический dashboard.
- Палитра: глубокий ночной синий, холодный индиго, лунный белый, мягкое золото и бирюзовый цвет подтверждения.
- Типографика: выразительный serif для заголовков; нейтральный системный sans-serif для объяснений; monospace только для коротких идентификаторов и статусов.
- Сигнатурный элемент: орбита из шести фаз, по которой движется световая точка-вопрос. Это единственный заметный декоративный жест.
- Анимация помогает увидеть последовательность, отключается при `prefers-reduced-motion`.

## Интерактивность

- запуск и пауза автоматического путешествия;
- переход к следующей и предыдущей фазе;
- прямой выбор фазы на орбите;
- переключатель «простое объяснение / что проверяется» без внутренних деталей;
- раскрываемые финальные разделы «Что система не обещает» и «Как запустить самому»;
- копирование короткого запускающего CLI-примера;
- клавиатурная навигация и заметный focus state.

## Технический формат

- Один файл `docs/jyotish-research-agent-explainer.html`.
- Весь CSS и JavaScript встроены; внешние библиотеки, шрифты и сетевые запросы отсутствуют.
- Страница работает при открытии с диска и адаптируется к мобильному экрану.
- Состояние хранится в одном JavaScript-объекте; все элементы отображаются из единого массива данных шести фаз.
- Страница не читает реальные birth data, SQLite или API.

## Проверка

- открыть файл локально и пройти все шесть фаз;
- проверить автоматический и ручной режимы, прямой выбор фаз и копирование команды;
- проверить ширины около 390, 768 и 1440 пикселей;
- проверить клавиатуру, focus states и reduced motion;
- убедиться, что текст не обещает объективную предсказательную достоверность и не скрывает ручные/external gates.

## Вне scope

- подключение к настоящему ResearchRun или FastAPI;
- отображение персональных birth data;
- выполнение астрологических расчётов внутри страницы;
- редактор настроек, экспорт memo или административный интерфейс;
- внешняя аналитика и сторонние зависимости.
